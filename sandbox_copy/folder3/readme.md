# folder3 - Documentation, Reports, and Support

Project knowledge base for the Bookstore Inventory app.

## Contents
- `folder31/` - feature specs, meeting notes, roadmaps
- `folder32/` - generated reports (weekly sales, inventory checks)
- `folder33/` - customer support tickets

## Reports
Reports in `folder32/` are regenerated every Monday from the orders
database. The SQL used is stored in `folder2/folder22/file222.sql`.
A sample report is in `folder32/file321.csv`.
