# UI Text Conventions

Applies to the storefront page (`file121.html`) and the
strings in `file1121.json`.

## Rules
1. All user-facing strings live in `file1121.json` - never hardcode
   them in `file122.js`.
2. Use "Unavailable" (not "Sold out") for zero-stock buttons.
3. Prices always show two decimals with a `$` prefix (`$9.99`).
4. Error messages start with the prefix from `app.error_prefix`
   and never expose SQL or stack traces.
5. Keep sentence case for buttons: "Order", not "ORDER".

## Why
Ticket #331 (folder3/folder33/file331.md) showed that confusing button
labels (an enabled "Order" on an out-of-stock row) directly caused
customer problems.
