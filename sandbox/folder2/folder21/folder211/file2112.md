# Alert Runbook - Bookstore API

For the endpoints listed in `file2111.xml`.

## Alert: `/api/books` failing (non-200)

1. Check whether the API process is running:
   ```bash
   python folder1/folder11/file111.py
   ```
2. Check the port in `folder2/folder21/file211.ini` matches
   `API_PUBLIC_URL` in `folder2/folder22/file221.env.example`.
3. Check the proxy log `folder2/folder21/file213.log` for recent errors.

## Alert: `/api/books/999` no longer returns 404

A 200 on the unknown-book endpoint usually means the seed data was
modified. Re-run the import script:

```bash
python folder1/folder11/file112.py
```

## Escalation
After 15 minutes, email `support@example.com`
(same contact as `folder2/folder22/file221.env.example`).
